# MoonBit Development Skills

MoonBit 開発スキル集。

## 含まれるスキル

- `beads_mbt/` - プロジェクト固有ガイド
- `sqlite/` - SQLite 連携ガイド
- `rust-porting/` - Rust CLI 移植ガイド
- `js-backend/` - JS バックエンド開発
- `wasm-cli/` - WASM CLI 開発
- `testing-strategy/` - テスト戦略（UT, E2E, QuickCheck）
- `mcp-gemini-cli/` - Gemini MCP 統合
- `moonbit-agent-guide/` - MoonBit 言語・ツールチェーンガイド（公式・vendor 版）

## 使い方

### サブモジュールとして追加

```bash
git submodule add https://github.com/utenadev/moonbit-skills.git .skills
```

### 各スキルの詳細

各ディレクトリの `SKILL.md` を参照してください。
